# Voice-Clone

**Voice Clone** is a web-based AI voice cloning platform that allows users to upload short audio samples of a person's voice and generate new speech in that cloned voice using a custom text prompt.

## Tech Stack
- Frontend: React 18 + Vite, TypeScript, Tailwind CSS
- Backend: FastAPI, Python 3.11, PostgreSQL
- ML/AI: Coqui XTTS v2, PyTorch
